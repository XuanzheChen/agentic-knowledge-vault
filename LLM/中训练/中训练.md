## 什么是中训练？

中训练（Mid-training）通常指在大规模通用预训练之后，继续使用较大规模数据对基础模型进行有目标的训练。它可以理解为一种更定向的 **继续预训练（Continued Pre-training）或特殊预训练**。

中训练真正要改变的，是模型已经形成的**能力分布**：在保留通用基础能力的前提下，通过继续进行大规模 token-level 训练，有意识地调整训练数据的质量与分布、上下文长度等，使特定能力进一步写入模型参数并得到强化，例如数学、代码、推理、领域知识、长上下文或 Agentic 基础能力。

因此，中训练不是简单地从已有 checkpoint 继续训练，而是围绕目标能力重新设计后续训练数据与训练过程，对 Base Model 进行进一步塑形。

> **中训练的核心是在已有通用能力之上，通过有目标的继续训练重新塑造模型的能力分布。**

“Mid-training”目前并不是所有团队都严格统一使用的术语，其具体边界会随模型训练流程而变化。

## 中训练的数据是什么样的？

中训练数据通常更强调**目标性、质量和可控性**，主要从三方面设计：

- **Data Mixture**：控制通用文本、数学、代码、科学、Agentic 等数据的采样比例，本质上是在分配训练预算并调整模型能力分布。
- **Data Quality**：关注样本是否正确、信息密度高、有足够难度与多样性，并做好去重和 benchmark 去污染；核心是单位 token 是否提供有效学习信号。
- **Synthetic Data（合成数据）**：由模型、程序或环境主动生成、重写、结构化或 rollout 得到的数据，用于补充真实数据中稀缺或希望精确控制的能力数据；关键在于后续验证与筛选。

> **Mixture 决定学什么，Quality 决定这些数据值不值得学，Synthetic Data 负责在真实数据不足时主动创造训练材料。**

## 中训练的能力目标有哪些？

中训练的能力目标可以概括为四类，它们并不完全互斥：

| 高层目标 | 主要强化什么 | 典型能力 |
|---|---|---|
| **Domain Coverage** | 模型熟悉和掌握哪些知识、语言与数据分布 | 领域知识、多语言、知识更新 |
| **Computation / Reasoning** | 模型处理复杂、强约束、多步问题的能力 | 数学、代码、科学推理、通用推理 |
| **Context Utilization** | 模型在更长工作空间中检索、保持并整合信息的能力 | 长上下文检索、长距离依赖、跨段信息整合 |
| **Interaction / Agency** | 模型根据外部反馈持续决策和行动的能力 | Tool Use、搜索、代码执行、Action–Observation 轨迹、长程 Agentic 任务 |

其中还有一个贯穿所有目标的约束：**Capability Retention**。中训练在增强目标能力时，应尽量避免通用语言、知识、多语言等已有能力明显退化，因此能力保持与 regression 检查也是中训练设计的重要部分。

从现代模型训练的角度，中训练不仅是在直接提高某项 benchmark，更是在为后续训练塑造更好的能力底座：例如数学、代码和复杂推理数据可以加强 reasoning substrate，长上下文训练提高信息工作空间，而 Agentic 数据让模型更熟悉“行动—环境反馈—继续决策”的交互模式。

> **中训练的能力目标，本质上是在已有 Base Model 上定向重塑“知道什么、如何计算、能利用多大的上下文，以及能否在环境反馈中持续行动”，同时尽量保留原有能力。**

## 中训练如何避免原有能力被破坏？

中训练会把模型继续推向新的数据分布，因此可能出现 **Capability Regression / Catastrophic Forgetting**：目标能力提高，但通用语言、知识、多语言、代码或 in-context learning 等已有能力下降。其本质是新的训练分布和梯度持续改变原有参数表示，因此需要在 **Plasticity（学习新能力）** 与 **Stability（保持旧能力）** 之间取得平衡。

常见保护手段可以分为几层：

| 层级 | 主要方法 | 核心作用 |
|---|---|---|
| **Data** | General Replay / Data Mixing | 在目标数据中持续混入通用数据，避免训练分布完全偏向新领域 |
| **Optimization** | 较小学习率、Annealing、控制训练 token、渐进式 curriculum | 限制参数漂移速度和幅度，减少突然的 distribution shock |
| **Parameter** | Freeze、Selective Update、PEFT | 限制能够被修改的参数范围，减少对原有表示的干扰 |
| **Objective** | Regularization、Distillation | 显式约束新模型不要偏离原模型的参数、表示或输出行为 |
| **Advanced** | Gradient Alignment、Capacity Expansion | 减少新旧任务梯度冲突，或为新能力增加独立容量 |

实际中最基础、最常用的仍是 **Data Mixture / Replay + 合理的 Learning-rate Schedule + 持续 Regression Evaluation**。过多目标数据、过大学习率或过长训练都会增加遗忘风险；但保护过强又会使新能力难以学入，因此目标不是让参数完全不变，而是在可接受的旧能力退化范围内获得足够的目标能力增益。

评估时应同时维护两组指标：

- **Target Suite**：检查数学、代码、推理、领域能力等目标能力是否提升。
- **Retention Suite**：检查通用知识、语言、多语言、ICL 等原有能力是否出现 regression。

> **中训练中的能力保持，本质上是一个 distribution management 问题：控制模型“看什么数据、按什么比例看、看多久、以多大的更新幅度学习”，再通过 retention benchmark 持续检查旧能力是否被破坏。**

## 中训练如何扩展模型的上下文？

中训练扩展上下文，不只是调大 `context length`，而是让模型同时获得**更大的可表示范围**和**真正利用长距离信息的能力**。通常包括四个部分：

1. **扩展位置表示**：对 [[RoPE]] 等位置编码进行插值或外推，使新的远距离 position 能被合理表示。
2. **长序列继续训练**：使用更长 sequence 继续做语言建模，使模型参数逐渐适应远距离依赖。
3. **长上下文数据设计**：加入长文档、跨段依赖、多文档整合、长距离检索等数据，迫使模型真正使用远处信息，而不只是“能装下更多 token”。
4. **Context Length Curriculum**：常从较短上下文逐步扩展到更长窗口，例如 8K → 32K → 128K，以降低训练分布突然变化带来的困难。

训练时通常还会混入一定比例的普通短文本与通用数据，避免在增强长上下文能力时造成原有能力退化。

因此要区分：**Max Context Window** 表示模型理论上能接收多长输入，**Effective Context Window** 才表示模型在多长范围内能够稳定检索、关联并利用信息。

> **长上下文扩展本质上是“位置表示扩展 + 长序列继续训练 + 长上下文数据 + 长度课程训练”的联合过程。**

## 中训练中的 Annealing / Learning-rate Schedule 是什么？

Annealing（退火）通常指在训练后期逐步降低学习率，使已经进入较好参数区域的模型从较大步幅的持续学习转向更细粒度、稳定的收敛。对现代 LLM 来说，它通常不只是单独调整 Learning Rate，而会与**数据分布调整**一起使用。

中训练阶段常同时发生两类变化：

- **Learning-rate Annealing**：逐步降低学习率，减小每次参数更新幅度和梯度噪声带来的扰动，使模型更稳定地收敛。
- **Data Annealing / Data Curriculum**：从覆盖广泛的数据逐渐转向更高质量、更目标化的数据，提高数学、代码、推理、科学等数据的占比，用更集中的训练信号塑造最终能力分布。

可以把两者理解为两个互补的旋钮：**Data Mixture 决定“往什么方向学”，Learning Rate 决定“还能沿这个方向改变多少”**。因此，中训练中的退火本质上常是 late-stage curriculum、distribution adaptation 与 learning-rate cooldown 的联合过程。

常见的学习率设计包括：

- **Cosine Decay**：学习率随预先确定的总训练步数逐渐下降，简单稳定，但通常需要提前知道训练 horizon。
- **WSD（Warmup–Stable–Decay）**：先 Warmup，再长时间保持较稳定学习率，最后在准备产出模型时进入 Decay。它把长期持续训练与最终收敛阶段解耦，便于从不同 stable checkpoint 继续训练后再单独 anneal。
- **Schedule Restart / Re-warmup**：如果中训练阶段的数据分布、上下文长度等发生较大变化，可以从 checkpoint 开启新的学习率周期，通过短暂 warmup 后再 stable / decay，使模型有足够可塑性适应新分布。

学习率需要在 **Plasticity（可塑性）** 与 **Stability（稳定性）** 之间权衡：过大容易破坏已有通用能力、增加 regression 或遗忘风险；过小则可能无法充分吸收新的目标数据。

阅读模型技术报告中的 annealing / cooldown / stage-2 pretraining 时，主要关注：**学习率从多少降到多少、采用什么 schedule、退火使用多少 token、数据 mixture 是否改变、是否重新 warmup、context length 是否变化，以及目标能力提升时原有能力是否出现 regression。**

> **Mid-training Annealing 的核心，是让“模型正在学什么”和“模型还能被改变多少”在训练后期同时收紧，从而把已有 Base Model 稳定地塑形成目标能力更强的版本。**
