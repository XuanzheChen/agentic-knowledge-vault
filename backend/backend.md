## XML 和 HTML 有什么区别？

**核心区别是用途不同：XML 侧重描述、存储和交换数据，HTML 侧重描述网页内容的结构与语义，供浏览器呈现给用户。**

- **XML（Extensible Markup Language，可扩展标记语言）**：关注“数据是什么、如何组织”。标签通常由使用者自定义，用于表达数据的结构和含义。例如，`<name>张三</name>` 表示一个名为 `name` 的数据字段。XML 常用于配置文件、系统间数据交换等场景。
- **HTML（HyperText Markup Language，超文本标记语言）**：关注“网页上有哪些内容，以及它们是什么”。HTML 使用标准化的语义标签（如 `<h1>`、`<p>`、`<table>`）组织网页，浏览器根据 HTML 及 CSS 将内容呈现出来。

| 对比维度 | XML | HTML |
| --- | --- | --- |
| 主要目标 | 表达数据结构、存储与交换数据 | 描述网页内容及语义，供浏览器展示 |
| 标签 | 可自定义，按约定解释 | 具有预定义的标准标签与浏览器语义 |
| 典型用途 | 配置、结构化文档、系统间数据交换 | 网页结构、文本、表单和交互界面 |
| 对展示的关注 | 默认不规定具体的页面展示效果 | 可由浏览器直接解析并渲染 |

需要注意，**“XML 用于数据、HTML 用于展示”是便于入门的概括，而不是绝对限制**：HTML 同样能够承载数据，XML 也可以配合 XSLT 等技术转换或展示。两者都属于标记语言，但设计目标不同。
